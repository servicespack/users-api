---
description: Coding style rules based on @antfu/eslint-config
---

When writing or modifying code in this project, you must follow the coding style enforced by `@antfu/eslint-config`.

Key rules to follow:
- **No Semicolons**: Do not use semicolons at the end of statements (rely on Automatic Semicolon Insertion).
- **Quotes**: Use single quotes for strings (except where escaping makes double quotes more readable).
- **Indentation**: Use 2 spaces for indentation.
- **Trailing Commas**: Add trailing commas in multiline object literals, arrays, and function parameters.
- **Arrow Functions**: Consistently use arrow functions for anonymous functions and callbacks.
- **TypeScript**: Follow TypeScript best practices (e.g., proper typing, avoiding `any` when possible, using interfaces/types appropriately).
